# Description

The general card list template, which dynamically renders each card-item based on dataSource.

## tagConfig

| property    | type    | required | default | description                                                                                                        |
| ----------- | ------- | -------- | ------- | ------------------------------------------------------------------------------------------------------------------ |
| text        | string  | -        | -       | The tag text. 1-2 characters are recommended                                                                       |
| field       | string  | ✔️       | -       | The deciding field for whether to show the tag, e.g. when the field is set to "default" and the value is true, it means the tag is shown only when `dataSource.default===true` |
| value       | string  | ✔️       | -       | The deciding value for whether to show the tag                                                                     |
| isNotEqual  | boolean | -        | false   | Show the tag when the corresponding field equals value                                                             |
| hideOperate | boolean | -        | -       | Hide the operation area when the tag is shown                                                                      |
