# Description

The general collapsible card list template, which dynamically renders each collapsible-card-item based on dataSource.

# INPUTS

| property                  | type                                                                                                                                             | required | default | description                                                                                                |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ | -------- | ------- | ---------------------------------------------------------------------------------------------------------- |
| showCard                  | boolean                                                                                                                                          | -        | true    | Whether to show the outer card                                                                             |
| dataSource                | Record<string, any>[]                                                                                                                            | ✔️       | -       | The data source of card information                                                                        |
| fields                    | { cardTitle?: string;icon?:string;cardDesc?: string; }                                                                                           | -        | -       | Field mapping. Used together with dataSource to obtain the runtime cardTitle and icon                      |
| cardTitle                 | string                                                                                                                                           | -        | -       | Card title                                                                                                 |
| cardDesc                  | string                                                                                                                                           | -        | -       | Card description                                                                                           |
| icon                      | MenuIcon                                                                                                                                         | -        | -       | Card icon                                                                                                  |
| iconStyle                 | Record<string, any>                                                                                                                              | -        | -       | The style of the card icon                                                                                 |
| operateBricks             | CustomBrick[]                                                                                                                                    | -        | -       | The bricks of the operation area slots.                                                                    |
| contentBricks             | CustomBrick[]                                                                                                                                    | -        | -       | The bricks of the content area slots.                                                                      |
| disableClickHeaderToOpen  | boolean                                                                                                                                          | -        | false   | Whether to disable expanding by clicking the card header (in some scenarios you do not want users to expand by clicking the header but to expand via a customized button, in which case it can be set to true) |
| disableClickHeaderToClose | boolean                                                                                                                                          | -        | false   | Whether to disable collapsing by clicking the card header (in some scenarios you do not want users to collapse by clicking the header but to collapse via a customized button, in which case it can be set to true) |
| customHeader              | boolean                                                                                                                                          | -        | false   | Whether to customize the header                                                                            |
| customHeaderBricks        | CustomBrick[]                                                                                                                                    | -        | -       | The bricks of the customized header slots.                                                                 |
| contentStyle              | Record<string,any>                                                                                                                               | -        | -       | The content area style. Currently the content area has a default padding of 32px 72px. When the bricks inside have their own margins, you need to adjust it yourself to achieve the desired style. |
| subscriptConfig           | {field: string; value: any; isNotEqual?: boolean; type?: "default"\|"checked"\|"custom"; subscriptIconConfig?: MenuIcon; hideOperate?: boolean;} | -        | -       | The top-right subscript                                                                                    |

# subscriptConfig

| property            | type                           | required | default   | description                                                                                                                                         |
| ------------------- | ------------------------------ | -------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| field               | string                         | ✔️       | -         | The deciding field for whether to show the subscript. For example, when the field is set to "default" and the value is true, it means the subscript is shown only when `dataSource.default===true`                                  |
| value               | string                         | ✔️       | -         | The deciding value for whether to show the subscript                                                                                                |
| isNotEqual          | boolean                        | -        | false     | Show the subscript when the corresponding field equals value                                                                                        |
| type                | "default"\|"checked"\|"custom" | -        | "default" | The icon type inside the subscript. The default is a five-pointed star (`default`), it can be set to checked (`checked`) in multi-select scenarios, or customized (`custom`). When set to `custom`, `subscriptIconConfig` must be set at the same time |
| subscriptIconConfig | MenuIcon                       | -        | -         | The label of the customized subscript                                                                                                                |
| hideOperate         | boolean                        | -        | -         | Hide the operation area when the subscript is shown                                                                                                 |

# CustomBrick

Composed of `BrickConf` extended with the following two properties

| property         | type                                                                                           | required | default | description                                                                                                                                                                                                                            |
| ---------------- | ---------------------------------------------------------------------------------------------- | -------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| propertyFieldMap | Record<string, string>                                                                         | -        | -       | Configures which field's data in the item the properties of this operation brick come from. For example, `{propertyFieldMap:{dataSource:"",name:"title"}}` means the`dataSource` property of this operation brick comes from `item`, and the `name` property comes from `item.title`. Both `key` and `value` support nested forms, e.g. `a.b.c` |
| eventMethodMap   | { eventName: string;method: "open"\| "close"\| "toggle"\|string;target?:string;args?:any[];}[] | -        | -       | Configures an event name and method of a child brick, which trigger the expand/collapse/toggle method of the corresponding `collapsible-card-item`. The target brick and args can also be configured.                                                                                                        |
