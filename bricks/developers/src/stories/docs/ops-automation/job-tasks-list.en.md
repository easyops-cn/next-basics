# Description

List of operation and maintenance automation job task records

# INPUTS

| property    | type   | required | default | description                                            |
| ----------- | ------ | -------- | ------- | ------------------------------------------------------ |
| jobId       | string | ✔️       | -       | Job Id                                                 |
| urlTemplate | string | ✔️       | -       | Target url for jumping from the task list; template variables are supported |
